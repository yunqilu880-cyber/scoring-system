# 评分系统

这是一个面向内部百人规模使用的专业技术岗位竞聘评分系统。当前版本支持真实后端、服务器数据保存、邀请码激活、图片材料上传、材料复评、评分项目配置、申报批次管理和排名导出。

## 演示账号

- 管理端：`admin` / `admin123`
- 用户端：`JS2026002` / `123456`
- 未激活申报人：由管理员在“申报人数据”中查看或重新生成邀请码后，用户通过“邀请码激活”设置自己的登录密码。

正式部署时，请通过环境变量或 `deploy/ecosystem.config.cjs` 修改管理员密码。

## 当前功能

- 用户使用邀请码激活账号，自行设置密码。
- 用户登录后选择评分项目，查看项目细则和材料要求，填写自评分、说明并上传证明图片。
- 后端保存申报人、邀请码、复评记录、评分规则、申报批次和上传图片。
- 管理员维护申报人基础数据，支持 CSV 导入导出。
- 管理员可重置用户密码并重新生成邀请码，可锁定或解锁账号。
- 管理员在线预览证明图片，通过、驳回或调整复评分。
- 每条申报自动生成编号，并记录提交、复评通过、复评驳回等操作痕迹。
- 管理员配置评分周期、总分上限、评分项目、项目满分、评分细则和材料要求。
- 管理员可按竞聘类别、奖项或专项活动新增申报批次。
- 排名结果自动统计复评通过的评分项目，导出 CSV 时包含分项得分，Excel 可以直接打开。
- 支持服务器 JSON 数据备份、恢复和一键重置演示数据。

## 本地运行

```bash
npm install
npm run build
npm start
```

访问：

```text
http://127.0.0.1:3000/
```

开发模式可以分别启动：

```bash
npm run dev:server
npm run dev
```

## 评分逻辑

```text
用户自评分 = 未被驳回的申报项目自评分合计
项目复评分 = 同一评分项目下复评通过分数合计，并受该项目满分限制
最终总分 = 各评分项目复评分合计，并受总分上限限制
```

默认采用 100 分制，分数保留两位小数。当前内置了工作年限、学历、年度与师德考核、专业技术职务、任职、综合奖、单项奖、个人业务竞赛、指导获奖、论文发表、论文获奖、新闻报道、课题研究、出勤、工作量、教育教学工作过程、教学效果等 17 个评分项目。
