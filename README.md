# 评分系统演示版

这是一个用于演示“用户上传加分项、审核员认定分数、系统自动汇总排名”的前端系统。

## 演示账号

- 用户端：`2021001` / `123456`，首次登录后需要修改密码
- 审核端：`admin` / `admin123`

## 当前功能

- 用户登录后上传加分项、申请分数、说明和证明图片
- 管理员导入名单后自动生成未激活账号，用户使用初始密码首次登录并修改密码完成激活
- 管理员可查看未激活、已激活、已锁定账号，并可重置用户密码
- 审核员筛选待审核材料，预览图片，通过、驳回或调整认定分数
- 每条申报自动生成编号，并记录提交、审核通过、审核驳回等操作留痕
- 管理员维护用户基础数据，支持 Excel/CSV 导入导出
- 管理员配置评分周期、基础指标权重、加分上限和加分类型
- 排名结果自动统计审核通过的加分项，支持导出 Excel
- 支持本地 JSON 数据备份、恢复和一键重置演示数据

## 评分逻辑

```text
基础指标分 = 基础表现 * 权重 + 综合表现 * 权重 + 贡献表现 * 权重 + 规范记录 * 权重
最终总分 = 基础指标分 + 审核通过的加分项总分
```

单个用户的加分总额会受到“单人加分上限”限制。

## 技术说明

当前版本是 React + TypeScript + Vite 的本地演示版，数据和图片保存在浏览器 localStorage 中。它适合演示业务流程；如果要给多人真实使用，需要增加后端数据库、附件存储、账号权限和数据备份。

正式上线时，用户密码应由后端加密保存，不能像演示版一样存放在浏览器本地。
