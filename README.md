# 评分系统

这是一个面向内部百人规模使用的加分项申报与材料审核系统。当前版本已经支持真实后端、服务器数据保存、邀请码激活、图片材料上传、管理员审核和排名导出。

## 演示账号

- 审核端：`admin` / `admin123`
- 用户端：`2021002` / `123456`
- 未激活用户：由管理员在“用户数据”中查看或重新生成邀请码后，用户通过“邀请码激活”设置自己的登录密码。

正式部署时，请通过环境变量或 `deploy/ecosystem.config.cjs` 修改管理员密码。

## 当前功能

- 用户使用邀请码激活账号，自行设置密码。
- 用户登录后上传加分项、申请分数、说明和证明图片。
- 后端保存用户、邀请码、审核记录、评分规则和上传图片。
- 管理员维护用户基础数据，支持 CSV 导入导出。
- 管理员可重置用户密码并重新生成邀请码，可锁定或解锁账号。
- 管理员在线预览证明图片，通过、驳回或调整认定分数。
- 每条申报自动生成编号，并记录提交、审核通过、审核驳回等操作痕迹。
- 管理员配置评分周期、基础指标权重、加分上限和加分类型。
- 排名结果自动统计审核通过的加分项，支持导出 CSV，Excel 可以直接打开。
- 支持服务器 JSON 数据备份、恢复和一键重置演示数据。

## 本地运行

```bash
npm install
npm run build
npm start
```

访问：

```text
http://127.0.0.1:3000/
```

开发模式可以分别启动：

```bash
npm run dev:server
npm run dev
```

## 评分逻辑

```text
基础指标分 = 基础表现 * 权重 + 综合表现 * 权重 + 贡献表现 * 权重 + 规范记录 * 权重
最终总分 = 基础指标分 + 审核通过的加分项总分
```

单个用户的加分总额会受到“单人加分上限”限制。
